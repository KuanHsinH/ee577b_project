# Iterative branch-predictor programs

These three programs exercise repeated branch predictions and recovery. Each
directory has an `imem.fill`, `dmem.fill`, and `expected_dmem.dump` compatible
with the Phase 2 testbench. Each executes fewer than 1,600 instructions;
the testbench's limit is 5,000 clock cycles.

| Case | Loop behavior | Key expected locations |
|---|---|---|
| `hot_taken` | 240 iterations; BEZ taken 240 times; BNEZ taken 239 times, then not taken | 16 = 0 (flushed store), 17 = 240, 18 = 0 |
| `alternating` | 256 iterations; one BEZ alternates taken and not taken; loop BNEZ is taken 255 times, then not taken | 16 = 128, 17 = 0, 18 = 0 |
| `nested` | 16 outer × 32 inner iterations; inner BNEZ exits and retrains on each outer iteration | 16 = 512, 17 = 0, 18 = 0 |

Copy this directory and `tests/cardinal_stress` under `tests/` in the Phase 2
simulation directory. Run one case at a time, for example:

```sh
make test IMEM=tests/cardinal_bp_loops/hot_taken/imem.fill DMEM=tests/cardinal_bp_loops/hot_taken/dmem.fill EXPECTED=tests/cardinal_bp_loops/hot_taken/expected_dmem.dump
make test IMEM=tests/cardinal_bp_loops/alternating/imem.fill DMEM=tests/cardinal_bp_loops/alternating/dmem.fill EXPECTED=tests/cardinal_bp_loops/alternating/expected_dmem.dump
make test IMEM=tests/cardinal_bp_loops/nested/imem.fill DMEM=tests/cardinal_bp_loops/nested/dmem.fill EXPECTED=tests/cardinal_bp_loops/nested/expected_dmem.dump
```

The program and expected files were generated by
`python -B tests/cardinal_bp_loops/generate.py`, using the sequential ISA model
from `tests/cardinal_stress/generate.py`. Memory results check correctness;
inspect BPB counters or PC traces in simulation to measure prediction accuracy.
